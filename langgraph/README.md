# LangGraph

This folder is about **LangGraph**, a toolkit for building AI workflows as a graph: a set of steps with arrows between them.

That makes it easier to add loops (“try again”), memory (“remember what we did”), and branches (“if this, do that”).

## What is in here

- Notebooks that introduce graphs, state, and multi-step agents
- A **Sidekick** app: a personal helper that can work through a request in your browser

## Who this is for

Anyone who wants an AI that does not just answer once, but follows a process until the goal is met.
