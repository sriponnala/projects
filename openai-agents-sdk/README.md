# OpenAI Agents SDK

This folder is about the **OpenAI Agents SDK**, OpenAI’s official library for building agents.

An agent here is a program that uses a language model, can call tools, and can hand work to other agents when needed.

## What is in here

Notebooks that walk through the basics: creating an agent, giving it tools, and running a small multi-agent flow.

## Who this is for

Anyone who wants a clear, official starting point for OpenAI-style agents, without a lot of extra framework on top.
