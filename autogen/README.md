# AutoGen

This folder is about **AutoGen**, a toolkit for building AI agents that can talk to each other and get work done as a group.

Think of one agent as a helper with a job. AutoGen lets several helpers pass messages, share results, and keep going until the task is finished.

## What is in here

- Notebooks that show how AutoGen chats and core pieces work
- An “agent creator” that can invent new agents from a template
- Sample agents and idea notes generated from that creator

## Who this is for

Anyone curious about AI teammates: one agent writes, another reviews, another keeps score, and they coordinate without you doing every step by hand.
