# Pydantic AI

This folder is reserved for **Pydantic AI**, a Python library for building AI agents with clear, typed inputs and outputs.

Pydantic is widely used to describe data shapes in Python. Pydantic AI uses that idea so an agent’s answers and tool calls stay structured and easier to check.

## What is in here

This folder is empty for now. New experiments and examples will go here.

## Who this is for

People who like agents that return reliable, well-formed results—not just free-form text.
