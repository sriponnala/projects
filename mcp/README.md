# MCP (Model Context Protocol)

This folder is about **MCP**, a simple way for AI agents to use tools and data.

Instead of baking every skill into the agent, you run small **servers** (look up an account, check a market, send a notice). The agent connects to those servers and calls them when it needs to act.

## What is in here

- Notebooks that show how MCP servers and clients fit together
- A **trading floor** demo: several trader agents with accounts, a market, and tools they can call

## Who this is for

People who want to understand how an AI can safely use real capabilities—data, actions, other programs—without you writing every action into one giant script.
