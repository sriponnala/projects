# Projects

Workspace for agentic AI experiments and applications.

## Stack

- Python
- OpenAI Agents SDK
- CrewAI
- LangGraph
- AutoGen
- Google ADK
- Pydantic AI
- Model Context Protocol (MCP)

Use free or low-cost models (Gemini, OpenRouter, and similar) as needed. Frontier APIs are optional.

## Local setup

1. Add project folders under this directory as you build them.
2. Create a Python environment per project (or one shared environment if you prefer).
3. Keep secrets in `.env` — do not commit API keys.

## Prerequisites

Python experience and some familiarity with LLMs help. Patience is the main requirement if you are newer to coding.
